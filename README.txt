# Merzouga Luxury Desert

Site vitrine responsive en HTML/CSS/JavaScript.

## Mise en ligne gratuite
1. Crée un compte GitHub.
2. Crée un nouveau dépôt, par exemple `merzouga-luxury-desert`.
3. Envoie `index.html`, `style.css` et `script.js`.
4. Dans Settings > Pages, active GitHub Pages sur la branche `main`.
5. Ton site sera accessible avec une adresse `github.io`.

## À personnaliser
- Numéro WhatsApp / téléphone
- Email
- Prix des circuits
- Photos
- Liens Instagram/Facebook
- Formulaire de réservation
- Nom de domaine personnalisé plus tard
